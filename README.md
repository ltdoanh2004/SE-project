
# 💎 AI Shopping System

An AI-powered web platform designed to revolutionize the online jewelry shopping experience with intelligent recommendations, real-time chatbot support, and immersive 3D customization tools.

## 🌟 Features

- 🔐 User authentication & profile management
- 💬 AI chatbot for real-time support
- 💡 Personalized product recommendations using AI
- 🛠️ Interactive 3D jewelry customization tool
- 🧠 AI-based design suggestions and dynamic pricing
- 📦 Order tracking, cart management, and checkout system
- 💳 Secure payment integration (MoMo, ZaloPay, etc.)
- 📝 Product feedback & wishlist functionality
- 🌐 Cross-device responsive UI
- 🔒 JWT-based authentication & RBAC security

## 🛠️ Technologies Used

**Frontend**
- React.js
- HTML, CSS, JavaScript
- React Router

**Backend**
- Node.js
- Express.js
- MySQL

**Other Tools**
- MongoDB (for data prototyping)
- GitHub for version control
- JWT, Bcrypt for authentication & security

## 🚀 Getting Started

### Prerequisites
- Node.js >= v16
- MySQL >= v8
- npm or yarn

### Installation

```bash
git clone https://github.com/ltdoanh2004/SE-project.git
cd SE-project
npm install
```

### Backend Setup

1. Configure your `.env` file for database credentials:
    ```
    DB_HOST=localhost
    DB_USER=root
    DB_PASSWORD=yourpassword
    DB_NAME=ai_shopping
    JWT_SECRET=your_jwt_secret
    ```

2. Run the server:
    ```bash
    npm run server
    ```

### Frontend Setup
```bash
cd client
npm install
npm start
```
