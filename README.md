# Jeify Jewelry E-commerce

An e-commerce website for jewelry with integrated AI jewelry consultant chatbot.

## Running the Project

### Backend Setup

```bash
cd be
npm install
npm run dev
```

### Frontend Setup

```bash
cd fe
npm install
npm run dev
```

## Features

- Product search and browsing
- User authentication
- Shopping cart and checkout
- Order management
- AI Jewelry Consultant Chatbot
  - Helps customers find the perfect jewelry
  - Provides personalized recommendations
  - Available through the chat icon in the bottom right

## Tech Stack

- Frontend: React, Vite, TailwindCSS
- Backend: Node.js, Express
- Database: MySQL
- Authentication: JWT
